Política de privacidad

Última actualización: 17 de noviembre de 2026.

1. Responsable

El responsable de esta política es ARO (Rolly Arnulfo López Aro), un pequeño negocio en Perú. Contacto para privacidad y eliminación de datos: rc1vjzcc@mail.grokbot.com.

2. Qué datos usamos

ARO Tech API solo se usa con las cuentas propias de ARO en TikTok: @aro.control, @aro_.oficial y @arotech_oficial. Los datos que puede recibir de TikTok, a través de Login Kit y la Content Posting API, son:

  • Información básica del perfil (permiso user.info.basic): por ejemplo el identificador de la cuenta, el nombre visible y la foto de perfil, para confirmar qué cuenta quedó conectada.
  • Carga de videos propios (permiso video.upload): el video que ARO envía y los datos técnicos necesarios para dejarlo como borrador en el buzón de TikTok de esa misma cuenta.

No pedimos permiso para publicar de forma automática en el perfil público. No usamos esta aplicación para acceder a cuentas de terceros ni para leer el contenido privado de otras personas.

3. Para qué los usamos

Usamos esos datos únicamente para operar la herramienta interna: identificar la cuenta autorizada y enviar videos propios al buzón de TikTok. No los usamos para publicidad, perfiles de marketing ni decisión automatizada sobre otras personas.

4. No vendemos datos y no los compartimos con terceros

No vendemos datos personales. No los compartimos con anunciantes ni con otras empresas para sus propios fines. El video y la autorización se envían a TikTok, que es la plataforma donde se abre el buzón. Este sitio informativo se publica en un alojamiento web; no incluye scripts de seguimiento ni herramientas de analítica.

5. Conservación

Conservamos solo lo necesario para mantener la conexión con las cuentas propias de ARO y para enviar borradores. Si se revoca el acceso o se pide la eliminación, dejamos de usar esos datos de TikTok para esta aplicación, salvo lo que la ley nos obligue a conservar.

6. Cómo revocar el acceso

Puedes quitar la autorización en TikTok, en los ajustes de la cuenta:

  1. Abre TikTok en tu celular y entra a Ajustes y privacidad.
  2. Ve a Seguridad y permisos (o Seguridad).
  3. Abre las aplicaciones autorizadas o los permisos de apps.
  4. Busca ARO Tech API y revoca o elimina el acceso.

También puedes escribirnos a rc1vjzcc@mail.grokbot.com para que dejemos de usar la conexión.

7. Cómo pedir la eliminación de datos

Para pedir que borremos los datos relacionados con esta aplicación, envía un correo a rc1vjzcc@mail.grokbot.com indicando de qué cuenta de TikTok se trata. Atenderemos la solicitud y te confirmaremos cuando esté hecha, dentro de un plazo razonable y de lo que permita la ley y la plataforma de TikTok.

8. Este sitio web

Estas páginas son informativas. No pedimos que crees una cuenta aquí y no usamos cookies de seguimiento ni scripts de analítica. La página /callback solo muestra, en tu propio navegador, los parámetros que TikTok devuelve en la dirección (como code o un posible error). Ese código no se guarda en nuestro servidor.

9. Cambios

Si actualizamos esta política, cambiaremos la fecha de “última actualización” en esta página.

English

Privacy Policy (summary)

ARO Tech API uses only ARO’s own TikTok accounts. It may receive basic profile information (user.info.basic) and may upload ARO’s own videos as drafts to the TikTok inbox (video.upload). We do not sell this data and we do not share it with third parties for their own purposes. TikTok is the platform that receives the upload. This website has no tracking scripts. You can revoke access in TikTok under Settings and privacy → Security and permissions → authorized apps, or email rc1vjzcc@mail.grokbot.com to request deletion. Last updated: November 17, 2026.
